# E-commerce Product Analytics and Experimentation

SQL-first product analytics portfolio using Google's public GA4 e-commerce sample dataset.

## Project status
In progress: project setup. No analysis results yet.

## Planned scope
- GA4 event data auditing and transformation with BigQuery SQL
- User and session analysis tables
- Session conversion funnel analysis
- Cohort retention analysis
- Channel, device, geography, product, and revenue analysis
- Simulated A/A testing, randomization checks, power, MDE, and sample size planning
- Streamlit dashboard and a one-page business decision report

## Data source
Table: `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`

Documentation:
https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset

## Experimentation disclosure
Experimental assignments will be simulated for educational purposes.
They will not be presented as results from a real randomized A/B experiment.
